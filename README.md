# Han Wai Htun — React Portfolio

A modern, multilingual portfolio built with React, Vite, and TypeScript.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Use `Ctrl+C` to stop the development server.

## Production build

```sh
npm run build
npm run preview
```

The portfolio supports English, Japanese, and Burmese, with responsive layouts, light and dark themes, project filtering, and an image viewer. CV download is not enabled.
